ESPACE COMMUNAUTAIRE — HAPPY LIFE
==================================

Ce script ajoute le nouvel espace communautaire à votre application :
inscription des clients (téléphone, WhatsApp ou email + mot de passe),
mur de photos avec commentaires publics, messagerie privée entre membres,
et un bouton "Partager" qui ajoute automatiquement le logo Happy Life en
filigrane sur la photo partagée en dehors de l'application.

INSTALLATION
------------
1. Dézippez ce fichier.
2. Copiez "1-Ajouter-espace-communaute.bat" et
   "ajouter-espace-communaute.ps1" dans votre dossier HAPPY_LIFE (à côté de
   package.json).
3. Double-cliquez sur "1-Ajouter-espace-communaute.bat".
4. Envoyez-moi le résultat affiché (25 fichiers doivent afficher "OK").
5. Committez et poussez depuis GitHub Desktop comme d'habitude, puis
   dites-moi de redéployer.

POINTS IMPORTANTS
------------------
• Code de vérification à l'inscription : aucun fournisseur SMS/WhatsApp
  n'est encore branché sur Happy Life (comme pour les rappels d'abonnement
  propriétaire). En attendant, le code à 6 chiffres s'affiche directement à
  l'écran après l'inscription — l'inscription est donc testable dès
  maintenant. Le jour où vous créez un compte chez un fournisseur SMS/
  WhatsApp (Twilio ou équivalent), je peux brancher l'envoi réel en
  quelques minutes.

• .gitignore : le script ne touche PAS ce fichier (pour éviter tout risque
  d'encodage). Vous pouvez, si vous le souhaitez, ajouter vous-même une
  ligne "data/uploads/" juste après la ligne "data/*.db" — cela évite
  d'envoyer sur GitHub les photos que vous publierez en testant. Ce n'est
  pas obligatoire pour que l'application fonctionne.

• Stockage des photos : comme le reste de l'application sur l'offre
  gratuite Render, les photos publiées dans la communauté ne sont pas
  conservées indéfiniment — un redéploiement réinitialise le disque
  (c'est déjà le cas aujourd'hui pour les fiches piscines/appartements,
  rien de nouveau ici).

• Filigrane : la photo d'origine affichée sur le mur n'a jamais de
  filigrane. Le logo Happy Life n'est ajouté que sur la copie générée au
  moment où un membre clique sur "Partager" (ex : vers WhatsApp).

----------------
