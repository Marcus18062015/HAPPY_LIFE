MOT DE PASSE OUBLIE — HAPPY LIFE
==================================

Ce script ajoute la fonction "Mot de passe oublié ?" aux deux espaces de
connexion : l'espace communauté (/communaute/connexion) et l'espace
propriétaire (/proprietaire/connexion).

INSTALLATION
------------
1. Dézippez ce fichier.
2. Copiez "3-Ajouter-mot-de-passe-oublie.bat" et
   "ajouter-mot-de-passe-oublie.ps1" dans votre dossier HAPPY_LIFE (à côté
   de package.json — le même dossier que la dernière fois :
   C:\Users\Marc\Desktop\Fichiers\HAPPY_PISCINE\HAPPY_LIFE).
3. Double-cliquez sur "3-Ajouter-mot-de-passe-oublie.bat".
4. Vérifiez que la première ligne affichée est bien "VERSION 1" et que les
   18 fichiers affichent "OK".
5. Envoyez-moi le résultat affiché.
6. Committez et poussez depuis GitHub Desktop comme d'habitude, puis
   dites-moi de redéployer.

COMMENT ÇA MARCHE
------------------
• Sur la page de connexion (communauté ou propriétaire), un lien
  "Mot de passe oublié ?" apparaît à côté du champ mot de passe.
• Comme aucun fournisseur SMS/WhatsApp/email n'est encore branché sur
  Happy Life, le code de réinitialisation à 6 chiffres s'affiche
  directement à l'écran, exactement comme pour l'inscription à la
  communauté — donc testable dès maintenant.
• Une fois le code saisi avec le nouveau mot de passe (deux fois, pour
  confirmation), le mot de passe est mis à jour et vous êtes ramené vers
  la page de connexion avec un message de confirmation.
• Le jour où vous créez un compte chez un fournisseur SMS/WhatsApp/email,
  je peux brancher l'envoi réel en quelques minutes — aucune autre partie
  de l'application n'a besoin de changer.

Testé de bout en bout (inscription, demande de code, réinitialisation,
connexion avec le nouveau mot de passe) sur les deux espaces avant envoi.
